# AI Study Assistant 🤖📚

An AI-powered study assistant built using Python and Generative AI. It helps students understand study materials, summarize notes, and practice multiple-choice questions.

## Features

- **PDF Upload:** Upload PDF documents and extract study material.
- **Ask AI:** Ask questions and get answers based on uploaded notes.
- **Smart Summarization:** Generate simple summaries of study materials.
- **Interactive MCQ Quiz:** Generate five multiple-choice questions.
- **Automatic Scoring:** Check answers and calculate quiz scores with explanations.

## Technologies Used

- Python
- Groq API
- Large Language Models (LLM)
- Gradio
- PyPDF

## Installation

1. Clone the repository:

   `git clone https://github.com/Navyasree-ux/AI_Study_Assistant.git`

2. Open the project folder.

3. Install the required libraries:

   `pip install -r requirements.txt`

4. Set your Groq API key as an environment variable named `GROQ_API_KEY`.

5. Run the application:

   `python app.py`

## Project Structure

- `app.py` – Main application code
- `requirements.txt` – Required Python libraries
- `README.md` – Project documentation

## Security

Keep your Groq API key private. Never upload API keys or passwords to GitHub.
